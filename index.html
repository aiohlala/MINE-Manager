新世代核心技術與現代系統適配

承襲最順手的經典多視窗手勢操作，注入 2026 最先進的原生系統工程

田

無限制 MDI 視窗與自由邊框縮放

預設開啟清爽單一視窗，隨時可展開 2、3、4、6、9+ 個子視窗並排或重疊；每個子視窗皆支援八方向邊框與四角自由拖曳縮放大小，跨視窗左鍵拖曳即可瞬間移動或複製檔案。

🖱️

MDIE 經典滑鼠手勢與右鍵選單

按住滑鼠右鍵劃出軌跡即可瞬間執行上一頁、下一頁、開關視窗或網格排版；原地點擊右鍵則彈出完整檔案操作選單，並支援按住右鍵＋滾輪極速捲動至清單首尾。

🛡️

純 Rust 記憶體安全與非同步沙盒

摒棄傳統舊式同步阻塞架構，全面採用 Rust 多執行緒非同步 I/O 與獨立沙盒防護機制，徹底改良舊世代軟體的閃退與無回應缺陷，任何高負載操作下主視窗永遠保持 60 FPS 流暢度。

💻

現代 64 位元作業系統與 4K DPI 適配

專為現代 Windows 10/11、macOS (Apple Silicon) 與 Linux 打造。採用 GPU 向量字型渲染，完美支援高解析度 Retina / 4K 螢幕縮放，工具列內建暗色、亮色與經典主題一鍵切換。

🔍

多核心平行檢索與條件自動勾選

內建多執行緒極速搜尋引擎，支援模糊拼字、檔案大小區間（如 `>10MB`）、副檔名篩選與檔案內文檢索，並重現按 Enter 一鍵自動勾選所有相符檔案的經典高效能操作。

🟢

系統磁碟自動整合與 100% 綠色便攜

自動偵測並整合系統檔案總管已設定之本機分割區與遠端網路資料夾，免去重複設定的繁瑣。所有個人化配置皆儲存於單一可攜式 JSON，隨身碟隨插即用。
