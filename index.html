解決原版 MDIE 與系統檔案總管的痛點

結合 2026 最新 Rust 安全架構與 Win11 / Win10 / macOS 跨平台優勢

功能與穩定性指標 Windows 10/11 內建總管 原版 MDIE (2007) 🚀 MINE (本專案)
視窗並排彈性 僅能單視窗分頁或貼齊2格 支援 MDI 多重視窗 無限制多視窗並排（左右、上下、網格、層疊任意組合）
滑鼠右鍵手勢 ❌ 無支援 ✅ 支援 ✅ 霓虹軌跡 HUD 滑鼠手勢 + 右鍵滾輪極速跳轉
特殊文字編碼資料夾 容易出現路徑解析錯誤 💥 Win32 ANSI 溢位直接崩潰 🛡️ 全 UTF-8/Lossy 容錯隔離，任何亂碼絕不閃退
.HEIC / 損毀圖檔預覽 COM 元件偶爾當機 💥 呼叫 Shell 介面直接崩潰閃退 🛡️ 獨立執行緒沙盒保護 (`catch_unwind`)，永遠安全
未連線 SMB 網路資料夾 💀 同步重試卡死 30~60 秒 💀 主視窗直接無回應 ⚡ 1.2 秒 TCP 快速逾時 + 獨立通道探測，零卡頓
搜尋引擎效能 速度緩慢且條件難下 單執行緒、容易漏檔 🚀 多執行緒支援模糊搜尋、>10MB 大小過濾、內文文字檢索與條件選取

打破雙欄檔案管理器的限制！同時開 3、4、6 個視窗並列或上下堆疊，跨資料夾拖拉、檔案移動比對一氣呵成，支援儲存多視窗工作區群組。

MDIE 經典滑鼠手勢

按住滑鼠右鍵劃出軌跡，瞬間上一頁、下一頁、關閉子視窗或並排排版。獨家支援右鍵按住＋滑鼠滾輪瞬間跳轉至清單開頭與結尾！

🛡️

沙盒防崩潰與解碼防護

遇到特殊的文字編碼資料夾絕不當機；點選 Apple HEIC/HEIF 高畫質照片或損毀圖檔時，獨立沙盒保證主程式永遠不閃退。

🌐

非阻塞式 SMB / NAS 連線

家裡或公司的 NAS/網域不在身邊？MINE 的背景非同步探測引擎自動在 1.2 秒內判定離線狀態，不會讓您對著轉圈圈的畫面發呆 60 秒。

🔍

次世代極速搜尋與條件勾選

支援多執行緒模糊拼字搜尋、大小過濾（如 `>10MB`）、副檔名（`ext:jpg,png`）與內文搜尋，更重現 MDIE 按 Enter 一鍵自動勾選所有符合項目的神技！

🟢

100% 綠色免安裝 / 隨身碟便攜

所有設定與分頁紀錄完整儲存在同目錄下的 `mine_config.json`，不污染 Windows 登錄檔。亦附帶一鍵安裝至系統資料夾右鍵選單的便捷腳本。
